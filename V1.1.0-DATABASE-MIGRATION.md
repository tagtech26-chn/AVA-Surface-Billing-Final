# v1.1.0 Database Migration

The v1.1 branch adds SQL Server entities for:

- Invoice cancellation/audit trail
- Customer categories and assignments
- Category price rules
- Customer-specific price rules
- Purchase headers/lines

From `server-dotnet`, generate and apply the EF migration against the target BillingDb:

```powershell
dotnet ef migrations add V1_1_EnterpriseManagement
dotnet ef database update
```

For production, review the generated migration before applying it to the live database. Do not delete or rewrite the v1.0 migration history.

After the database update, validate:

```sql
SELECT TABLE_NAME
FROM INFORMATION_SCHEMA.TABLES
WHERE TABLE_NAME IN (
  'InvoiceCancellations',
  'CustomerCategories',
  'CustomerCategoryAssignments',
  'CategoryPriceRules',
  'CustomerPriceRules',
  'Purchases',
  'PurchaseLines'
);
```
